# LDR Birthday Surprise ❤️

A no-build, mobile-friendly birthday surprise website.

## 1. Personalize it

Open `script.js` and edit the `CONFIG` object:

- `name` — birthday person's name
- `from` — your location/name
- `to` — their location/name
- `birthday` — birthday date/time
- `signature` — your sign-off
- `finalMessage` — final screen message
- `surprise` — final surprise text

## 2. Add photos

Replace:

- `assets/photo1.jpg`
- `assets/photo2.jpg`
- `assets/photo3.jpg`

with your own images. Keep the same filenames.

## 3. Add your song

Put your own audio file at:

`assets/our-song.mp3`

The browser will start it after the first button interaction. The music button can then pause/resume it.

## 4. Run it

Double-click `index.html`, or upload the folder to any static hosting service.

No Node.js, npm, database, or server is required.

## Flow

1. Intro
2. Long-distance / same-sky moment
3. Birthday countdown
4. Photo memories
5. Reasons / little things
6. Personal letter
7. Confetti + final surprise

You can edit the wording directly in `index.html` if you want a more personal story.
